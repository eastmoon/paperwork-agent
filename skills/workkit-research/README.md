## 調查與研究

使用 `/workkit-research`，基於調研描述產生調研文件

```markdown
/workkit-research
+ 研究項目 : [本研究的主題]
+ 程式語言 : [範本指定的程式語言]
+ 調研描述 : [調研項目描述]
+ 描述文件 : [指定檔案目錄與描述檔案名稱]
+ 輸出文件 : [指定檔案目錄與檔案名稱]
```

技能使用注意事項：

+ 技能路徑需為根目錄開始的完整路徑。
+ **研究項目** 是本研究主的主要名稱，此為必要資訊不可為空。
+ **調研描述** 與 **描述文件** 會互相疊加。
+ **輸出文件** 是調查與研究報告的輸出文件位置，此為必要資訊不可為空。
+ **程式語言** 是用於基於調研項目產生範例程式，若未提供則不會產生範例。
